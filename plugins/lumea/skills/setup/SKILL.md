# Настройка подключения к Lumea

1. Выполнить `jq --version`. Нет `jq` — сказать, что хуки плагина без него не разбирают вызовы и просят подтверждение на каждый пишущий инструмент с пометкой «jq не установлен»; предложить `brew install jq`. Дальше продолжать: ключ и права от `jq` не зависят.
2. Вызвать `whoami`.
3. **Ответ пришёл** — вывести: имя, роль, число прав (для роли `admin` — «все», а не число: у неё нет строк `role_grants`, `permissions` придёт пустым, а доступ у неё безусловный по обходу в `can()`), затем таблицу «скилл → доступен?» по правам:

   | Скилл       | Нужны права                                                                                                                                                   |
   | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | digest      | `ticket.list`                                                                                                                                                 |
   | sweep       | `ticket.list`; по действию правила — `ticket.status`, `ticket.priority` или `ticket.tags`                                                                     |
   | groups      | `ticket.list`, `issue.read`                                                                                                                                   |
   | case        | `ticket.list`, `ticket.tags`, `message.send`; `show` — ещё `ticket.view`, `message.read`, `client.view`                                                       |
   | collect     | `ticket.list`, `message.read`, `message.send`, `broadcast.create`                                                                                             |
   | resolve     | `ticket.list`, `ticket.view`, `message.read`, `client.view`, `issue.read`, `project.read`, `message.send`, `broadcast.create`, `ticket.status`, `ticket.tags` |
   | client      | `client.view`, `search.query`, `ticket.list`, `client.external.view`                                                                                          |
   | investigate | `ticket.view`, `message.read`                                                                                                                                 |
   | issue       | `ticket.list`, `message.read`, `issue.draft`, `issue.create`, `issue.link`                                                                                    |
   | watch       | `ticket.list`, `message.read`                                                                                                                                 |

   Право считается выданным, если в `permissions` есть точный ключ, маска `resource.*` или `*`, либо роль `admin`. Недоступные скиллы перечислить с правом, которое нужно попросить у администратора на странице ролей. Часть возможностей `client` требует прав сверх базовых — их отсутствие не делает скилл недоступным целиком, но соответствующее действие скилл откажет выполнить: блокировка/разблокировка клиента — `client.block`/`client.unblock`, действие во внешнем сервисе — `client.external.action`.

4. **401 или инструмент недоступен** — сначала попросить выполнить `/mcp` и посмотреть статус сервера `lumea` (точный текст статуса не гарантирован — ориентироваться по смыслу, не искать конкретные слова): ошибка авторизации/«нужна аутентификация» значит дело в ключе (не тот скопирован, отозван, истёк, опечатка, неверный формат — не обязательно «нет ключа вовсе»); ошибка на стороне сервера/«не удалось» — переходить сразу к шагу 5, новый ключ не поможет. При проблеме с ключом объяснить по шагам:
   - Lumea → Настройки → «Ключи доступа» → «Создать ключ» (кнопка есть только у ролей с правом «Выпускать ключи доступа для MCP и API»); ключ `lmk_…` показывается один раз;
   - положить ключ в окружение: `export LUMEA_ACCESS_KEY=lmk_…` в `~/.zshrc` **или** блок `"env": { "LUMEA_ACCESS_KEY": "lmk_…" }` в `~/.claude/settings.json`; для стенда дополнительно `LUMEA_URL=https://…`;
   - после смены переменной — новый терминал или новая сессия Claude Code (переменные окружения процесс читает при старте), затем `/reload-plugins` и снова `/lumea:setup`.
   - Если ключ был и перестал работать: его отозвали, он истёк или у роли отобрали право выпускать ключи — выпустить новый.
5. **500 «Сервер настроен неверно»** — дело не в ключе: на сервере не задана переменная окружения; позвать администратора, новый ключ не поможет.

Ничего, кроме `jq --version` и `whoami`, не вызывать. Ключ в ответе не печатать, даже если пользователь его вставил в чат.
