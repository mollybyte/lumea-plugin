# Инструменты MCP Lumea

_Файл сгенерирован `bun run scripts/plugin-tools-reference.ts` из `evals/mocks/lumea/_tools.json`; не править руками._

Инструментов: 41. Порядок — как в `tools/list` сервера. Все id — полные uuid; короткий `#1d2155` сначала разрешить через `search`.

## `whoami`

Кто владелец ключа: id, имя, роль, права.

Без аргументов.

## `list_projects`

Проекты Lumea: id, название и type. projectId нужен фильтрам и внешним данным.

Без аргументов.

## `list_staff`

Сотрудники: id, имя, роль, kind (human/ai). id нужен для assignedTo и фильтров аудита.

Без аргументов.
