# Сводка

Аргументы: `$ARGUMENTS` — период (`shift` по умолчанию; `24h`; `7d`; или две даты) и, если названо, имя проекта.

1. Один вызов `ticket_digest { period, projectName? }` → `{ period: { from, to }, counts: { created, closed, unansweredNow, inProgressNow }, firstResponseMedianSeconds, topTags: [{ name, count }], stale: [{ ticketId, ticketRef, title, projectId, waitingSeconds }], team: [{ staffId, name, replies, closed }] }`. `team` — `[]` без права `statistics.read`: тогда строку про команду просто не печатать, без извинений.
2. Составить текст для вставки в чат (Markdown, до 25 строк). Шапку строить из `period.from`/`period.to` самого ответа, не из текущей даты; проект в шапке — только если в аргументах был назван (`projectName` передавался в вызов), иначе шапка без проекта. Числа: `counts.*`; медиана — `firstResponseMedianSeconds` в минутах (`null` — строку не печатать); зависшие — до 5 записей из `stale[]` (`ticketRef`, `title`, `waitingSeconds` в часах и минутах; какой возраст считать «зависшим» решает сам `ticket_digest`, в тексте это не переформулировать порогом вроде «>2 ч» — просто перечислить, что вернулось); команда — до 5 записей из `team[]` (`name`, `replies`, «закрыто N», не «закрыла/закрыл»).

```
📊 Сводка · Проект · смена 15.09 09:00–21:00
🆕 Новых: 42 · ✅ Закрыто: 37 · ⏳ Без ответа сейчас: 6 · 🔧 В работе: 9
⏱ Первый ответ: медиана 4 мин
🔥 Темы: bug (11), payment (6), promo (4)
🧊 Зависли: #1d215500 iMac, браузеры не через VPN — 3 ч 10 мин; …
👥 Ответили: Алина — 18, закрыто 4; Ангел — 12, закрыто 2
```

3. Топ-темы — до 5 записей из `topTags` (`name`, `count`) плюс заголовки зависших; если тегов нет — сгруппировать заголовки по смыслу самому, не выдумывать числа.
4. Ничего не менять и не отправлять; это чтение.
