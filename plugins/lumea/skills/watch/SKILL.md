# Фоновые уведомления

Аргументы: `$ARGUMENTS` — `case <slug>`, `project <имя>`, `all` или `off` (без аргументов — показать текущий фильтр).

1. Выполнить `lumea-watch config $ARGUMENTS` (исполняемый файл плагина, он на `PATH`, пока плагин включён). Команда печатает одну строку — показать её пользователю как есть.
2. Первый вызов скилла в сессии запускает монитор автоматически; последующие только меняют фильтр — монитор перечитывает его сам.
3. Объяснить одной фразой, что дальше: строки вида `🔔 <slug> · #ref <клиент> прислал файл …` будут приходить в разговор сами; по файлу предлагать `/lumea:collect fetch <slug>`.
4. `off` — фильтр пустой, монитор спит без запросов; выключить полностью можно только перезапуском сессии.
5. Если команда ответила «не задан `LUMEA_ACCESS_KEY`» — показать это и предложить `/lumea:setup`; монитору нужен Node ≥ 18. Состояние (фильтр, курсор) лежит в `~/.lumea/` (`LUMEA_WATCH_DIR`) и общее для всех сессий на машине — активное наблюдение одно на машину, вторая сессия перезапишет фильтр первой.

Ничего другого не вызывать.
