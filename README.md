# Lumea — плагин для Claude Code

Публичный маркетплейс плагина `lumea` ([Lumea](https://crm.sotaservers.cloud) — CRM поддержки Sota VPN и Faygo VPN). Версия плагина совпадает с версией сервера; репозиторий обновляется автоматически с каждым релизом.

```
/plugin marketplace add mollybyte/lumea-plugin
/plugin install lumea@lumea
```

Ключ доступа выпускается в Lumea (Настройки → «Ключи доступа») и задаётся переменной `LUMEA_ACCESS_KEY`. Подробности, список скиллов и проверка — [plugins/lumea/README.md](plugins/lumea/README.md).

Обновление: `/plugin marketplace update lumea`, затем `/plugin update lumea`.

Текущая версия: **0.38.2**.
